SHUMDEV LEAD HUNTER v0.3.6 — ЗАЯВКИ, ЗАДАЧИ И КОНТАКТЫ

Перед обновлением сделайте резервную копию базы:
  npm run db:backup

Остановите оба процесса (npm run dev / npm run worker) через Ctrl+C.
Скопируйте патч с заменой файлов в каталог LeadHunter.
НЕ переносите .env, dev.db, node_modules из архива. Патч их не содержит.

Команды в папке проекта:
  npm install
  npm run db:generate
  npm run db:deploy
  npx prisma migrate status
  npm run build
  npm run dev

Во втором CMD:
  npm run worker

Если в папке есть package-lock.json, npm install при обновлении не обязателен:
проект не добавляет зависимостей. Если npm install неудобен, выполните
только db:generate, db:deploy, build.

Теперь в меню есть «Заявки». Создание заявки внутри карточки компании.
Указываются канал, сумма, комментарий, статус. Все заявки видны общим списком.
Задачи создаются в карточке компании или в отдельном разделе «Задачи».
Открытые задачи отображаются на страницах CRM, Заявки и Задачи.

По контактам:
- 2ГИС без разрешения items.contact_groups по-прежнему не предоставляет сайты и телефоны.
- В результатах поиска есть ссылка «Найти сайт и телефон в интернете»;
  это переход к ручной проверке, а НЕ автоматическое извлечение из поисковой системы.
- В CRM у компании с известным сайтом нажмите «Проверить»: аудит пробует
  найти номера в tel:, schema.org JSON-LD, контактной странице собственного сайта.
- Единственный найденный корректного формата номер записывается автоматически,
  несколько номеров остаются кандидатами на ручную проверку.
- Подтверждается только формат номера, НЕ его доступность.

ВАЖНО: миграция добавляет таблицу Inquiry без удаления существующих данных.
Демо-ключ 2ГИС не даёт автоматически права хранить каталог в CRM.
