ShumDev Lead Hunter v0.3.5 — категории, телефоны, разрешённый импорт
====================================================================

Установка ПАТЧА поверх установленного v0.3.4 на Windows CMD:

1. Остановите оба окна: npm run dev и npm run worker (Ctrl+C).
2. Не удаляйте .env и prisma/dev.db. Резервная копия SQLite:

   cd /d "C:\Users\Павел.DESKTOP-JFFFGLC\Work\LeadHunter"
   npm run db:backup

3. Если архив скачан в стандартные «Загрузки», распакуйте:

   tar -xf "%USERPROFILE%\Downloads\shumdev-lead-hunter-v035-patch.zip" -C .

4. Протестируйте новые модули:

   node --test tests/contacts-categories-v035.test.js

5. Запустите заново (в отдельных окнах CMD):

   npm run dev
   npm run worker

6. Обновите страницу сочетанием Ctrl+F5.

Что изменилось:
- 123 ниши, включая шаурму/шаверму и спортзалы/фитнес-клубы.
- В предпросмотре Яндекса при наличии ключа показывается телефон из CompanyMetaData.Phones.
- В 2ГИС при отдельном доступе items.contact_groups показывается телефон.
- Формат номера проверяется; факт доступности номера НЕ проверяется.
- Для разрешённых источников добавлена галочка «Автоматически сохранять показанную страницу в CRM».
- Если права на хранение отсутствуют, галочка даёт понятную ошибку, просмотр остаётся временным.
- При повторном импорте у существующей компании заполняются отсутствующие телефон, email, сайт (старые не перезаписываются).
- Если включена проверка сайтов, из HTML tel:-ссылок собственного сайта ищется номер.
  При единственном подходящем номере он добавляется в карточку без перезаписи старого.

ВАЖНО ПРО ЛИЦЕНЗИИ И ТЕЛЕФОНЫ
- Наличие демо-ключа 2ГИС НЕ является разрешением на долговременное хранение выдачи.
- Для 2ГИС данные разрешено записывать только по подходящему договору:
  DGIS_STORAGE_ALLOWED=true — только при подтверждённом праве хранения.
- DGIS_CONTACTS_ALLOWED=true — только после выдачи 2ГИС доступа к items.contact_groups.
- По стандартной лицензии API поиска организаций Яндекса нельзя сохранять результат в CRM.
- Оставляйте оба флага хранения false, пока нет разрешения.
- Ни один сервис не гарантирует телефоны у каждой организации.

ЯНДЕКС API
Существующий адаптер использует официальный HTTP API Поиска по организациям.
Ключ для него указывайте в .env: YANDEX_MAPS_API_KEY=...
Перезапустите сервер, выберите поисковую фразу и нажмите «Посмотреть Яндекс».
В обычной лицензии хранение Яндекса недоступно, в CRM не импортируется.

Пересобирать SCSS не требуется — стили не изменены.
Prisma schema и миграции не менялись, db:deploy не требуется.

Важно: дополнительные динамические проверки с ключами 2ГИС и Яндекса и живой
запуск на Windows должны быть выполнены в вашей среде. Здесь проверены
синтаксис JS и автономные unit-тесты без API-ключей.
