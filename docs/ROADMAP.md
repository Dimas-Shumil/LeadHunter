# Roadmap — SQLite

1. Windows Node 24: npm install + Prisma generate/deploy, unit/integration тесты, login OWNER.
2. Реальный пробный поиск OpenStreetMap/Overpass по 1 нише; повторить для дедупликации, убедиться, что worker пишет в ту же SQLite, что сервер.
3. Проверить импорт XLSX/CSV, CRM, заметки, задачи, фильтры, отмену задания.
4. Проверить консистентность резервной копии и восстановление.
5. Подключить лицензированные источники 2ГИС/Яндекс по действующим ключам/правам и проверить лимиты, качество найденных организаций.
6. После реальных результатов внедрять дополнительный поиск сайтов и регулярный запуск по расписанию.

Ключевой критерий: реальные компании появляются в «База клиентов» после ручного запуска поиска, без подмены тестовыми данными.
