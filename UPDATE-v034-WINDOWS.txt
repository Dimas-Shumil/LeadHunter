SHUMDEV LEAD HUNTER — ПАТЧ ПОИСКА v0.3.4
=======================================

ЧТО ДОБАВЛЕНО
- 72 направления бизнеса в группах + быстрый фильтр по названию ниши.
- Свободный запрос по названию компании или услуге (например «Эвакуатор19»).
- Прямой ПОКАЗ выдачи 2ГИС через API, без записи организаций в SQLite.
- Опциональный прямой ПОКАЗ выдачи Яндекса при наличии ключа API поиска организаций.
- Постраничный просмотр (до 5 страниц по 10 результатов для демо-режима 2ГИС).
- Геоограничение 2ГИС по city_id, если API возвращает однозначный ID города.
- Чёткое разделение «Посмотреть каталог» и «Запустить импорт в CRM».
- Включение «Сайт не указан» не требуется для проверки известной компании: используйте «Любой».

ВАЖНО
- Это дополнение к уже установленному Lead Hunter v0.3.2. Не запускайте повторную миграцию базы.
- Патч НЕ содержит .env, prisma/dev.db или dev.db, поэтому не стирает учётку и текущие данные.
- DGIS_STORAGE_ALLOWED=false оставьте без изменений, пока нет прав на накопление CRM-базы.
- DGIS_CONTACTS_ALLOWED=false оставьте, если вашему ключу не предоставлен доступ к items.contact_groups.
- При этих настройках 2ГИС показывает имя и адрес организации, но НЕ обязан возвращать сайт или телефон.
- Яндекс использует ОТДЕЛЬНЫЙ YANDEX_MAPS_API_KEY; если ключа нет, кнопка Яндекса отключена.
- Обычный автоматический импорт из OSM и прочих разрешённых источников по-прежнему работает через воркер.
- Данные каталога, показанные в предпросмотре, в базу SQLite не записываются.
- OSM НЕ обеспечивает полный охват: отсутствие записи там ничего не говорит о наличии в 2ГИС.

УСТАНОВКА (CMD)
1. Остановите сервер и воркер (Ctrl+C в каждом окне).
2. В CMD перейдите в существующую папку LeadHunter:
   cd /d "C:\Users\Павел.DESKTOP-JFFFGLC\Work\LeadHunter"
3. На всякий случай сделайте резервную копию проекта/БД.
4. Распакуйте патч ПО ПУТИ к открытому проекту:
   tar -xf "%USERPROFILE%\Downloads\shumdev-lead-hunter-search-v034-patch.zip" -C .
5. Пересоберите стили:
   npm run build
6. Проверка новых модулей:
   node --test tests/preview.test.js
7. Окно CMD №1:
   npm run dev
8. Окно CMD №2:
   npm run worker
9. Обновите страницу браузера Ctrl+F5 и перейдите в «Поиск организаций».

ТЕСТ «ЭВАКУАТОР19»
- Город: Абакан; регион: Республика Хакасия.
- Сайт в справочнике: ЛЮБОЙ (не «Сайт не указан»).
- Свободный запрос: Эвакуатор19.
- Нажмите «Посмотреть 2ГИС».
- При необходимости проверьте также «эвакуатор» и следующие страницы выдачи.
- В блоке результата будут имена, адреса, ссылки на карточки и общий объём выдачи.
- Телефон/сайт отображаются только при наличии доступа к contact_groups.

ПОЧЕМУ МОЖЕТ НЕ НАЙТИ КОМПАНИЮ
1. Компания не попала в возвращённую API релевантную выдачу.
2. Название отличается от поисковой фразы.
3. Включён фильтр «Сайт не указан», исключающий компании, у которых есть сайт.
4. У конкретного источника неполное покрытие.
5. Демо-ключ имеет ограничения количества выдаваемых страниц и запросов.
6. Если ID города не найден, поиск использует лишь название города в тексте; это менее строгое ограничение.

Если выдача пустая, проверьте вторую поисковую фразу. В этой версии пока нет гарантированного
полного охвата организаций, автоматического нахождения отсутствующего URL и импорта данных
2ГИС без разрешения на накопление.
