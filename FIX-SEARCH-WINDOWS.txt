ShumDev Lead Hunter — hotfix поиска v0.3.2 (9 октября 2026)
==========================================================
Исправляет две ошибки заданий:
1) 2ГИС / Яндекс: "DNS содержит приватный или зарезервированный адрес"
   Для ТОЛЬКО фиксированных официальных API URL используется Node fetch
   с TLS-проверкой, запретом редиректов, таймаутом и ограничением ответа.
   Общая защита от SSRF при проверке сайтов организаций НЕ изменена.
2) Overpass: "Query ran out of memory"
   Запросы OSM ограничены небольшими bbox известных городов вместо дорогостоящего
   вложенного поиска RU -> регион -> город; потолок maxsize увеличен до 128 MiB.

Установка на существующий проект LeadHunter (не новый проект):
1. Остановить ДВА окна CMD с 'npm run dev' и 'npm run worker' через Ctrl+C.
2. Распаковать этот ZIP поверх корневой папки LeadHunter (папки src и tests должны слиться).
   CMD:
     cd /d "C:\Users\Павел.DESKTOP-JFFFGLC\Work\LeadHunter"
     tar -xf "%USERPROFILE%\Downloads\shumdev-lead-hunter-search-fix-v032.zip" -C .
3. Проверить патч:
     node --test tests/search-fix.test.js
4. В первом CMD:
     npm run dev
5. Во втором CMD:
     cd /d "C:\Users\Павел.DESKTOP-JFFFGLC\Work\LeadHunter"
     npm run worker
6. Открыть http://localhost:3000 -> Поиск организаций.
   Пробный поиск: Абакан, одна ниша (например, Автосалоны и мотосалоны),
   источник OpenStreetMap, сайт любой, лимит 10, аудит сайтов выключен.
   Затем проверить источник «Автопоиск».

Переустановка зависимостей, Prisma-миграция, создание OWNER и npm run build НЕ нужны.
База prisma/dev.db и .env не меняются.

ВАЖНО:
- 2ГИС API может работать, но сохранить результаты в локальную CRM система
  разрешает только если DGIS_STORAGE_ALLOWED=true и у вас есть соответствующие права.
  Обычный демо-ключ сам по себе таких прав не подтверждает.
- Если DGIS_STORAGE_ALLOWED=false, автопоиск использует другие READY-источники,
  обычно OpenStreetMap.
- Overpass — общедоступный ресурс; успешное выполнение сетевого запроса не
  гарантировано. Покрытие ниш неполное.
- Облегчённый поиск OSM ограничен 8 городами: Абакан, Черногорск, Саяногорск,
  Минусинск, Красноярск, Новосибирск, Иркутск, Кемерово.

Проверено при подготовке: 6 тестов, синтаксис файлов, целостность ZIP.
НЕ проверено: подключение к живому API в пользовательской сети и полный запуск
на Windows (Node 24 + Prisma).
